# Shopping App Project

A simple shopping app that allows users to register/login, browse products by categories (Indian Wear, Western Wear), add products to a cart, and place orders. This project is developed in Python with a focus on object-oriented design and basic shopping functionalities.

## Features

- User registration and login
- Product browsing by category
- Cart functionality with add/view products
- Total bill calculation
- Order placement and confirmation

## Project Overview

This app simulates an online shopping experience where users can select from different product categories, add items to their cart, and place orders with a total bill. The project utilizes classes such as User, Product, Category, Cart, and Order to model the core entities and their interactions.

## Tech Stack

- Python 3.x
- Object-oriented programming principles
  ## Usage

- The app runs in the console/terminal.
- Follow on-screen prompts for adding products to the cart and placing orders.

## Class Diagram

The project contains the following core classes with relationships:
- **User**: Represents an app user with personal details and a cart.
- **Category**: Product categories like Indian Wear and Western Wear.
- **Product**: Product details including category and price.
- **Cart**: Contains products selected by the user.
- **Order**: Contains order details and total bill.
